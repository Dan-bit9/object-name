# 쑥쑥 사물 학습

어린이가 사진으로 일상 사물의 이름을 배우고, 목표 사물을 맞히는 로컬 웹앱입니다. 이름 알려주기와 맞히기 모드를 제공하며 브라우저 음성 합성으로 결과를 읽어 줍니다.

## 설치

Python 3.10 이상을 설치한 뒤 PowerShell에서 프로젝트 폴더로 이동합니다.

```powershell
python -m pip install -r requirements.txt
```

가상환경은 필수가 아닙니다. Windows에서 `python` 명령이 없으면 설치된 Python의 전체 경로를 사용하세요.

## 모델 준비

이 앱은 torchvision의 사전학습 ResNet-18 ImageNet 모델을 CPU로 사용합니다. 별도의 모델 파일을 저장소에 포함하지 않습니다. 서버를 처음 실행할 때 PyTorch가 모델을 자동 다운로드하며, 인터넷 연결이 필요합니다. 이후에는 사용자 Python 캐시에 보관되어 재사용됩니다.

## 실행

```powershell
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

브라우저에서 <http://127.0.0.1:8000>을 열고 사진을 선택하거나 카메라로 촬영합니다. 카메라와 음성 재생은 브라우저 권한 및 지원 여부에 영향을 받습니다.

지원 대상은 컵, 물병, 의자, 공, 신발, 가방, 우산 등을 포함한 33개 사물입니다. 허용 목록 밖이거나 신뢰도가 낮은 결과는 `잘 모르겠어요`로 표시됩니다. 인공지능 결과는 틀릴 수 있습니다.

## 구성

- `app.py`: FastAPI 서버와 이미지 분류 API
- `static/`: 웹 UI, CSS, 브라우저 JavaScript
- `requirements.txt`: 실행 의존성

## 주의

업로드된 이미지는 서버 메모리에서만 처리하며 프로젝트 폴더에 저장하지 않습니다. 모델 캐시, 로그, 테스트 이미지 등은 저장소에 올리지 않습니다.
